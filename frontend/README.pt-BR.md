# Frontend

Frontend em React + Vite para a rede social.

## Início Rápido

```bash
# Instalar dependências
npm install

# Configurar o ambiente
cp .env.example .env

# Iniciar o servidor de desenvolvimento
npm run dev
```

O frontend roda em `http://localhost:3000`

## Build

```bash
npm run build
npm run preview
```

## Arquitetura

- **Framework**: React 18
- **Ferramenta de build**: Vite
- **Cliente HTTP**: Axios
- **Estilização**: CSS modules

## Funcionalidades

- Autenticação de usuário (login/cadastro)
- Feed com publicações
- Criação de publicações com suporte a mídia
- Reações às publicações

## Design

- Cores primárias: verde (#10b981) e branco
- Layout minimalista
- Design responsivo
- Tipografia limpa
